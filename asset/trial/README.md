Generated using the built-in image_gen tool. Exact prompts are saved in `prompts.json`.

## Review notes

The previews establish a muted, matte, faceted visual direction. The hands/sleeves and rifle contain more small facets and surface texture than the original reference; simplify those in a refinement pass if close matching is the priority.

The hand image is a material/anatomy preview, not a verified production pose. Confirm anatomical handedness and watch/bandage placement when drawing the actual HD poses. The letter image needs its two tri-fold crease positions checked before unfolding animation. Raster transparency alone does not provide separate hand, sleeve, bandage, sling, paper and drawing layers.
