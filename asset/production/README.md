# Asset generation status

Images are generated with the built-in imagegen tool, using the three original style trials and the approved style in the root AGENTS.md.

Naming: `CATEGORY-ID_subject_state_v1.png`. Original style trials are preserved at the asset root. New artwork is organized into backgrounds, characters, hands, props and effects. Authored text and audio work belong in text and audio. Prompts and inventory records belong in production.

This pass produces static artwork, character key-state sheets, hand poses and effect source images. A state sheet is not a finished frame-by-frame animation. Environment previews are flattened paintings, not separately painted parallax masters. Do not mark animation, layer separation, final resolution or audio recording complete based on an image file existing.

The generation manifest records the final prompt for each image. A final inventory audit records which script IDs have artwork and which production requirements remain.
