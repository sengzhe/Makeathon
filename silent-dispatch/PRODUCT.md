## Platform
web
## Stack
User confirmed buildless HTML, CSS and JavaScript and direct implementation from the supplied newspaper reference.
## Product Purpose
A newspaper landing page for an interactive 2.5D WWII scene.
## Capabilities and Constraints
User requests a generated monochrome, low-detail stylized 2.5D battlefield image centered within newspaper text. Clicking starts programmatic animation, not video. The page returns when animation completes. Ominous chaotic black ink moves behind words in frequent bursts, with soft translucent shadows that preserve readability and tiny ghostlike image movement occur at rest. Scene implementation must be replaceable.
Latest user correction: reduce detail and apparent pixel resolution so the landing artwork matches an unrealistic 2.5D animation, avoiding a visual fidelity drop. Keep the site local.

## Brand Commitments
User-provided wartime newspaper screenshot establishes the visual world. Fictional publication name and prose are creative prototype content, not historical reporting.
## Open decisions
Audience, final publication name and final animation remain unspecified.
